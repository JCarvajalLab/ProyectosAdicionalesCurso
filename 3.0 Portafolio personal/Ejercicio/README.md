# 📌 Portfolio HTML & CSS Practice Project

## 📖 Descripción

Este proyecto consiste en la construcción de un portfolio multi-página utilizando únicamente **HTML y CSS**, aplicando buenas prácticas modernas como:

- Mobile First
- Flexbox
- CSS Grid
- Variables CSS
- Media Queries
- Estructura semántica

El objetivo fue desarrollar una estructura limpia, organizada y responsive sin utilizar frameworks externos como Bootstrap.
